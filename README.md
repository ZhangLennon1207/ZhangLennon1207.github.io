# BebopNeverStop

Zhang Lennon 的个人博客：鸵鸟与大象的漫游。

## 写文章

1. 打开 [Pages CMS](https://app.pagescms.org)，用 GitHub 登录。
2. 进入 `ZhangLennon1207/ZhangLennon1207.github.io`，选择“文章”。
3. 新建文章，填写标题、摘要、栏目和正文；图片可直接上传或插入。
4. 新文章默认开启“草稿”，草稿不会出现在公开网站。准备好后关闭草稿并保存。
5. 保存会触发 GitHub Pages 自动发布，通常几分钟后可在网站看到更新。

“关于我”也可以在后台直接修改。需要精确编辑 Markdown 或 HTML 时，在正文编辑器切换到“源代码”。

## 更新首页的歌、书和电影

在后台打开「生活的 B 面 · 听读记录」，修改作品名称、音乐人、随记与链接，保存即可。随记可以留空；无需每次都写评论。

- Apple Music 的歌曲或专辑链接会生成「试听这首歌」入口，点击后才加载官方播放器；完整播放由音乐平台提供。其他平台的链接也可以填写，会显示直达入口。
- 有权公开分享的音频可直接上传到「可播放音频」，网站会使用自带播放器。
- 在文章中开启「首页置顶」，即可把文章放在首页前面；归档和 RSS 仍按日期排列。
- 原创文章自动显示 MIT 许可。转载文章填写原作者、来源和授权链接，单独标注许可。

## 阅读与外观

界面右上角可切换中英文，文章保留原文。外观默认跟随系统，也可手动选择亮色或暗色；选择会在浏览器中记住。文章页可切换专注阅读，按 Esc 返回；带 Markdown 标题的文章自动生成目录。顶部细线显示阅读进度，分享按钮调用系统分享或复制链接。

## 访问统计

统计默认关闭。注册 [GoatCounter](https://www.goatcounter.com/) 后，在「生活的 B 面」中填写站点代码（`xxx.goatcounter.com` 中的 `xxx`），保存后启用。没有配置代码时不会加载统计脚本。评论和邮件订阅暂未开启。

首页首批听读信息由 Zhang Lennon 提供；作品链接对应 [寸铁歌曲](https://music.apple.com/cn/song/1519218391)、[马世芳书籍](https://read.douban.com/ebook/11945662/)、[电影资料](https://movie.douban.com/subject/34941536/)。仅列作品及创作者，不代写个人评价。

> 仓库是公开的，因此草稿正文虽然不会出现在网站页面，仍会保存在公开的 GitHub 仓库里。私密草稿请先留在本地笔记中。

## 本地预览
