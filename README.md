# BebopNeverStop

Zhang Lennon 的个人博客：鸵鸟还是大象的漫游。

## 写文章

1. 打开 [Pages CMS](https://app.pagescms.org)，用 GitHub 登录。
2. 进入 `ZhangLennon1207/ZhangLennon1207.github.io`，选择“文章”。
3. 新建文章，填写标题、摘要、栏目和正文；图片可直接上传或插入。
4. 新文章默认开启“草稿”，草稿不会出现在公开网站。准备好后关闭草稿并保存。
5. 保存会触发 GitHub Pages 自动发布，通常几分钟后可在网站看到更新。

“关于我”也可以在后台直接修改。需要精确编辑 Markdown 或 HTML 时，在正文编辑器切换到“源代码”。

> 仓库是公开的，因此草稿正文虽然不会出现在网站页面，仍会保存在公开的 GitHub 仓库里。私密草稿请先留在本地笔记中。

## 本地预览

在项目上一层运行 `start-preview.ps1`，然后打开 <http://127.0.0.1:4321/>。

网站基于 [Astro](https://astro.build/) 和 [Fuwari](https://github.com/saicaca/fuwari) 构建。
